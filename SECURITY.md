# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** option in the Security tab. Do not disclose an unpatched vulnerability in a public issue.

Include the affected version, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within seven days.

FeatureBuilder projects can contain confidential design information. Review a project before sharing it and do not store secrets in feature fields or attachments.
